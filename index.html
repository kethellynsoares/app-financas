Sincronização com o Nubank
A ponte busca os lançamentos do cartão no banco (Open Finance) e guarda as chaves de acesso fora do app. Compras feitas nos cartões acima, ou até a data acima, entram como de outra pessoa. A senha da ponte fica só neste aparelho e não vai para o backup.

Qualquer pessoa com este aparelho pode abrir o app.
Os dados deste aparelho ficam criptografados com a senha. O app bloqueia sozinho quando fica 1 minuto em segundo plano ou 10 minutos parado. A senha vale só para este aparelho: crie uma em cada um. Se esquecer, dá para apagar os dados do aparelho e importar o backup de novo.
Backup e outros aparelhos
Os dados ficam guardados só neste navegador. Para usar no celular ou em outro computador: Salvar backup aqui, guarde o arquivo no OneDrive e, no outro aparelho, Importar backup. A importação junta os dados — nada é apagado.
